# Modern Multi-Page Developer Portfolio 🚀

Welcome to my personal developer portfolio! This repository contains the source code for my fully custom, multi-page digital showroom. It is built to display my engineering milestones, technical projects, freelance work, and academic background with a polished user experience.

🔗 **Live Demo:** [https://Imad-Khan-Software.github.io/developer-portfolio/](https://Imad-Khan-Software.github.io/developer-portfolio/)

---

## ✨ Features

* **Modular Multi-Page Architecture:** Divided cleanly into distinct contextual pages (`index.html`, `about.html`, `projects.html`, `skills.html`, etc.) for optimal performance and clean routing.
* **Persistent Dark/Light Mode Engine:** A custom configuration using `localStorage` ensures that the user's preferred visual theme stays saved across page changes and browser sessions.
* **Asynchronous Multi-Phrase Typewriter:** Built with pure client-side JavaScript to cycle through professional roles seamlessly in the hero section.
* **Fluid Responsive Layouts:** Crafted from scratch using modern CSS properties, Flexbox, and CSS Grid without bloated frameworks.
* **Integrated Form Handling:** Connected to reliable asynchronous processing to handle dynamic freelance project inquiries on the fly.

---

## 🛠️ Built With

* **HTML5:** Structured with strict semantic components to promote accessibility and modern SEO standards.
* **CSS3 (Design Tokens):** Engineered using centralized CSS variables (`:root`) for global color, font spacing, and theme alignment.
* **JavaScript (ES6+):** Utilizes lightweight vanilla DOM manipulation for navigation mechanics, theme transitions, and scroll animations.
* **Google Fonts:** Typographically stylized using high-contrast combinations of *Syne*, *DM Sans*, and *DM Mono*.
