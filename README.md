# Modern Multi-Page Developer Portfolio 🚀

A responsive multi-page developer portfolio built from scratch using **HTML5, CSS3, and Vanilla JavaScript**.

This project showcases my frontend development skills, projects, education, experience, certifications, and professional journey.

🌐 **Live Demo:** https://developerportfolio21.netlify.app

---

## ✨ Features

- 📱 Fully responsive design
- 🌙 Dark/Light mode with saved user preference
- ⌨️ JavaScript typewriter effect
- 🎨 Custom CSS design system
- 📐 Flexbox and CSS Grid layouts
- 🧭 Multi-page navigation
- ✨ Scroll and UI animations
- 📩 Contact/inquiry form
- ♿ Semantic HTML structure
- 🔍 SEO-friendly page structure
- 💻 Clean and maintainable code

---

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript (ES6+)
- CSS Variables
- Flexbox
- CSS Grid
- LocalStorage
- Google Fonts
